# How the proof got here (archived history)

The proof of `PAL ∈ PEG` in `proof/` was developed in the public repository `kmizu/lean4-peg` between 2026-09-07 and
2026-09-24 (about 1,500 commits, pull requests #5–#79) and then moved here without its history. On 2026-10-03
`kmizu/lean4-peg` was recreated without that history. The individual commits are not kept anywhere; this file records
only the main turns of the route and what each turn taught. 日本語の要約は末尾。

## 1. The composition argument (2026-09-03 → 09-07)

- Background in lean4-peg: problem T7 (`CFL ⊆ PEL`, Ford 2004). The textbook palindrome grammar transcribed into a PEG is
  sound but incomplete (2026-07-24).
- Kim and Park (arXiv:2608.29592, 2026-08-30) settled T7 negatively. Composing Galil 1978 (palindromes in real time on a
  multitape Turing machine), Kim–Park's compiler from real-time Turing machines to scaffold automata (SCA), and LMR's
  `L ∈ PEG ⇔ Lᴿ ∈ SCA` gives `PAL ∈ PEG` and refutes LMR's Conjecture 7.
- First Lean version: on top of the Kim–Park artifact, with Galil's theorem as the only assumption. A plain PEG for PAL
  was generated by a Python generator; the reference implementation was then ported from Python to Scala.

## 2. Formalizing the Galil machine (09-07 → 09-17, PR #7–#9)

To remove the assumption, the Galil machine itself was assembled in Lean: the machine, oracle leaves for its sub-runs,
trail induction, fairness and fuel segments, and local realization of its ticks.

## 3. The closeout waves: reducing hypotheses (09-17 → 09-19, PR #10–#74)

About sixty "closeout" pull requests drove the top theorem's list of hypotheses down (counts such as 8 → 7 → 5) through
invariants, run forms and ledgers. Several hypotheses that had been carried as leaves turned out to be **false** on real
runs (`ScanRealized`, `H_candOrient`, `hws`, `hpack`, a margin premise), and some reductions only traded one hypothesis for
others. An audit fixed the canonical statement (eight hypotheses), and the work was handed off with two axioms left.

Lessons: reduce hypotheses only when they can really be reduced; bundling a leaf into a stronger one can make it false;
check what a leaf's consumer needs before quantifying it; model the machine as a function, not a relation; an obligation
with no producer means the formalization is wrong; when a proof balloons, suspect the signature first.

## 4. One common machine (09-20 → 09-23, PR #75–#79)

The cycle-oracle obligation was proved (axioms 2 → 1), and the tick's branches were carried one by one on a single common
machine (restart first, the alias mechanism, the right-moving cursor, the matched arm's readings), then re-pointed to the
physical machine with a freeze design.

## 5. The turn: no Turing machine, mirror the Scala route (09-23)

Instead of Galil's Turing machine, the proof followed the route of the Scala implementation directly: scaffold automata
over finite types, persistent stacks on a scaffold heap, a window controller that recognizes PAL given its workers, and the
real head-program workers. Tables were tied to coroutines by kernel-checked certificates, multi-stack machines were compiled
to scaffold automata, and the controller became one stack program per letter. This is the route the final proof takes.

## 6. Closing the timing (09-24)

The top theorem was reduced to promises about the real workers (output contracts, lifetimes, the matcher and the flags
loops), then to two step-count facts. A gap appeared: the step bound available for one decomposition was too small for the
service quanta. The fix was to raise the quanta (matcher 512 → 2048, flags 1024 → 32768) rather than tighten the proof.
With that, `PalPeg.PalInPeg.unconditional` was proved with only the standard axioms, and `evenPal_in_peg` refutes LMR's
Conjecture 7 unconditionally.

## 7. The move (09-24 → 10-03)

The proof was trimmed to 78 modules, a root and an axiom audit, moved to this repository, and the Python reference was
dropped (the Scala implementation remains the reference). Work after the move — the size of the generated PEG — lives in
`research/` with its own history.

## 日本語の要約

`proof/` の `PAL ∈ PEG` の証明は、2026-09-07〜09-24 に公開リポジトリ `kmizu/lean4-peg` で作られ（約 1,500 コミット、PR #5〜#79）、
履歴なしでここへ移した。2026-10-03 に `kmizu/lean4-peg` はその履歴なしで作り直したので、個々のコミットはどこにも残っていない。
主な方針転換：

1. **合成の議論**：Galil 1978（回文の実時間 TM）＋ Kim–Park の TM → SCA コンパイラ＋ LMR の `L ∈ PEG ⇔ Lᴿ ∈ SCA`。最初は Galil の定理を仮定。
2. **Galil の機械の形式化**で仮定を消そうとした。
3. **closeout の波**（PR 約 60 本）：最上位の前提を減らしていったが、葉として運んでいた前提のいくつかが実際の走行で偽だった
   （ScanRealized、H_candOrient、hws、hpack ほか）。教訓：前提は本当に減らせるときだけ減らす、葉を強い葉に束ねると偽になりうる、
   モデルは関係でなく関数で写す、producer のない義務は形式化が間違い。
4. **共通の機械**の上で tick の分岐を 1 本ずつ運んだ（公理 2 → 1）。
5. **転換**：TM をやめ、Scala 実装の経路（scaffold automata、永続スタック、窓の制御器と実ワーカー、カーネル検査つき証明書で表＝
   コルーチン）をそのまま写した。最終証明はこの経路。
6. **時間の閉じ方**：分解に回せる歩数が足りない穴が見つかり、証明を締めるのでなく量子を上げて解決（照合器 512 → 2048、フラグ
   1024 → 32768）。`PalInPeg.unconditional` を標準 3 公理だけで証明し、LMR の Conjecture 7 を無条件に反証。
7. **移動**：78 モジュールに整理してこのリポジトリへ移した。その後の PEG の縮小の研究は `research/` に履歴つきである。
